# Publishing screenshots

[M5Chord Keyboard view](M5Chord-keyboard.png) is a lossless 240×135 PNG of the actual firmware renderer, generated by `tools/ui_preview.cpp`. It shows CHORD mode with the major-quality control held, M7 stacked and C4 input. Transport indicators are not fabricated as connected.

This is a native rendered preview with simulated input, not a photograph or screenshot retrieved from a physical Cardputer. Suggested caption: **M5Chord — live Keyboard view (firmware-rendered preview).**

Reproduce with `SDL_VIDEODRIVER=dummy build-preview/midi_ui_preview build-preview/publishing`, then convert `M5Chord-keyboard.ppm` to PNG losslessly. No AI-generated artwork or redraw is used.
